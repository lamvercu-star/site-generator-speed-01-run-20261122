A faster drop-in for make.fun's own makefun-site 1.0.0: `solve.js` answers exactly as makefun-site does on every case — same output tree, byte for byte — with a fused single-pass Markdown renderer, a fast template engine, and per-case caching of site-only partials. No dependencies, no WASM, no native code; Node 22, JavaScript only.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
